# What raw text does `sherpa-onnx-nemo-parakeet-tdt-0.6b-v3-int8` emit for German?

Research date: 2026-09. Model: `nvidia/parakeet-tdt-0.6b-v3` (ONNX int8 port used by yappr).
Evidence: NVIDIA model card, Granary paper/pipeline, tokenizer inspection of the local model,
and **two first-hand local decoding runs** (no microphone used).

Companion files:
- `.research-granary.md` — Granary training-text pipeline, with quotes.
- `.research-parakeet-de-empirical.md` — public reports + a 30-clip read-speech run.

---

## TL;DR for building the training set

| Question | Answer |
|---|---|
| Q2 Punctuation/casing | **Yes, both.** Full sentence casing + `. , ? !`. German nouns are capitalized. |
| Q4 Numbers | **Inconsistent.** Spontaneous small numbers came out as WORDS in 5/5 of my cases; digits do appear for years / prices / list markers in other users' transcripts. Synthesize both forms. |
| Q3 German casing | Noun capitalization works. Occasional lowercase sentence start / lowercase noun. |
| Q5 Fillers | **Kept.** `äh`, `ähm`, `also` appear verbatim in my spontaneous-speech run. |
| Q6 Errors | Compound splitting, anglicism spacing, English leakage, wrong-word substitutions, empty output on noise. |

The ASR output is **already sentence-shaped German**, not a lowercase unpunctuated stream.
Input-side training data must look like clean-but-imperfect German prose, not like Whisper-tiny output.

## 1. Is Parakeet TDT 0.6b v3 multilingual, and is German included?

**Yes.** Model card (https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3):

> `parakeet-tdt-0.6b-v3` is a 600-million-parameter multilingual automatic speech recognition (ASR)
> model ... It extends the parakeet-tdt-0.6b-v2 model by expanding language support from English to
> 25 European languages. The model automatically detects the language of the audio and transcribes
> it without requiring additional prompting.

Supported: bg, hr, cs, da, nl, en, et, fi, fr, **de**, el, hu, it, lv, lt, mt, pl, pt, ro, sk, sl,
es, sv, ru, uk.

German is one of the best-served languages: FLEURS de WER **5.04 %**, CoVoST de **4.84 %**
(vs. 25-language average 11.97 % / 11.98 %). Training data: **29,279.61 h** German from Granary
plus 2,602.24 h human-transcribed (Parakeet v3 report, arXiv 2509.14128, Appendix A).

Caveat printed on the card: *"WERs are calculated after removing Punctuation and Capitalization
from reference and predicted text."* So the published WER says nothing about casing quality.

## 2. Punctuation and capitalization — THE key question

**The model emits punctuation and capitalization.** Three independent statements on the card:

> * Automatic **punctuation** and **capitalization**   (Key Features)

> **Other Properties Related to Output:** Punctuations and Capitalizations included.   (Output section)

> All transcriptions preserve punctuation and capitalization.   (Training Dataset section)

Confirmed by my own run (26 non-empty German clips, spontaneous telephone speech):
**26/26 start with a capital letter, 26/26 end with `.`, `?` or `!`**, 48 commas, 12 question marks.

### The punctuation alphabet is small and fixed

Inspection of the shipped `tokens.txt` (8,193 SentencePiece pieces) — the complete set of
non-alphanumeric tokens the model can ever emit:

```
, . - ' ? ! : % / $ € £ ¿ ¡   (plus the pieces ",-" ",." "--" "¡¡")
```

There is **no `"`, no `„ “`, no `;`, no parentheses, no ellipsis `…`, no `–` en-dash**.
The ASR can never produce German quotation marks or a semicolon. My run only ever produced
`. , ? '`. Do not put quotes, semicolons, brackets or ellipses on the INPUT side of the training set.

This matches the Granary pipeline: punctuation was restored by Qwen2.5-7B-Instruct, and the German
prompt restricts marks to `. , ? ! ; : -` (see `.research-granary.md`).

## 3. German-specific casing, umlauts, ß

**Noun capitalization is real, not sentence-initial only.** My spontaneous run capitalizes
`Übersicht, Zahlungen, Konto, Geld, Geldautomaten, Bankkarte, Gemeinschaftskonto, Limit, Karte,
Kredit, Automaten, Funktionen, Partner, Ausland, Australien`. The 30-clip read-speech run measured
a capitalized-word rate of **28.5 % (hypothesis) vs 27.6 % (reference)** — i.e. statistically
identical to correct German, with **zero nouns left lowercase** in that sample.

Known failures (rare, but real):
- a sentence can start lowercase when the utterance is a fragment (`"als eine Fortbildung ..."`);
- a user-posted transcript ends `"Wie stand der dinge ist"` — lowercase noun and no final stop.
- Cause: the Granary P&C prompt explicitly says *"Wenn der Text mitten in einem Satz beginnt,
  schreiben Sie das erste Wort nicht groß und fügen Sie keinen Punkt am Ende hinzu."* So the model
  learned that a fragment may legitimately start lowercase and end unpunctuated.

**Umlauts and ß are fine.** 194 vocabulary tokens contain `ä ö ü ß`. Read-speech run: 51 umlauts in
hypotheses vs 52 in references. The model even **prefers `ß` over Swiss `ss`** (`bloss`→`bloß`,
`stossen`→`stoßen`). The one public "broken umlauts" bug report against this exact int8 file was a
Windows console encoding problem, not the ASR ("German transcription itself works as expected").

So: **do not** build training pairs that fix casing of nouns or repair `ss`→`ß` as the main job.

## 4. Numbers: digits or words?

**Both occur. This is the least stable part of the output.**

First-hand, spontaneous German (telephone, MINDS-14 de-DE), reference vs hypothesis:

| Reference (human) | ASR output |
|---|---|
| `in den letzten 7 Tagen` | `in den letzten **sieben** Tagen` |
| `letzten 7 Tagen` | `letzten **sieben** Tagen` |
| `der letzten 4 Wochen` | `der letzten **vier** Wochen` |
| `für 2000 €` | `für ca. **zwei tausend** Euro` |
| `für einen Kredit ... 29` | `... **zwei neuen** Krediten` |

**0 of 26 outputs contained a single digit.** Small quantities in fluent speech came out as words —
and note `zwei tausend` was even split wrongly, and `ca.` was written as an abbreviation.

Counter-evidence from other users' German transcripts (HF discussions, see companion file):
`"1250 Euro netto"`, `"1. Die Anreise. 2. Die Unterkunft."`, `"Bilanz 2025"`, `"Herr Dr. Weber"` —
digits for prices, years and enumerations. In the same transcript, `"drei Fragen"` stayed a word.
HF discussion #34 documents the instability directly for French: the same `09:30` audio decoded once
as `"neuf heures trente"` and once as `"9h32"`.

Root cause (Granary): **there is no ITN step at all.** The pipeline only tags data (`"itn": "itn"`)
and keeps whatever Whisper-large-v3 wrote. Measured on 11,834 released German Granary segments:
digits in **8.8 %** of segments, spelled-out numbers ~0.13 %; style is German written form
(`10,86`, `96,1 %`, `20.000`, `10.000 Euro`, `am 26. Januar`, `um 9 Uhr`, `70%`).
**No `14:30`-style clock times were found** — `:` only ever appears as punctuation.

### Consequence for the training set
- Do **not** assume `14:30`. That exact form is essentially absent from the training distribution.
  Expect `um 9 Uhr`, `um halb drei`, `um vierzehn Uhr dreißig`.
- Include **both** digit and word forms of the same number on the input side, in roughly the
  proportion observed: words dominate for small counts in speech; digits appear for years, prices,
  percentages, ordinals/enumerations and larger round numbers.
- German written conventions when digits do appear: decimal **comma** (`10,86`), thousands **dot**
  (`20.000`), ordinal dot (`26.`), `%` attached or spaced inconsistently.

## 5. Disfluencies and fillers

**Kept, verbatim — when the speaker actually produces them.**

From my spontaneous run (raw output, unedited):

> `Hallo, ich versuche gerade, **ähm** nein, Fernsehen zu kaufen für ca. zwei tausend Euro. Und **äh**,
> ich versuche online zu bezahlen, aber ich ständig nur eine SMS mit einem Bezahlungscode und ich habe
> keine Ahnung. Was **uh** was das bedeutet, was was soll ich denn damit machen?`

> `Ja, hallo, ich informier mich **äh**, ich möchte mich hier mit für ein Kredit informieren.`

> `Ja, ich muss an, weil ich **äh** ganz schnell wegen der wegen der Arbeit ...`

Counts over 26 clips: `äh` ×3, `ähm` ×1, `uh` ×1, `also` ×3, discourse-`Ja` ×3. Word repetitions are
also kept (`wegen der wegen der`, `was was`, `ob es ob ich irgendwo einsehen kann`).
`äh` / `▁äh` are real vocabulary tokens.

The 30-clip **read**-speech run found 0 fillers — because read speech has none. So filler rate in the
training input should track the speaking style you expect (dictation ≈ spontaneous ⇒ include them).

Supporting: the Granary P&C prompt forbids changing words (*"Ändern, hinzufügen oder entfernen Sie
keine Wörter im Text"*); only whole-segment hallucination filtering exists. Measured `äh/ähm` in
0.5 % of German Granary segments. Whisper-large-v3, the teacher, tends to drop fillers, so expect
them under-represented relative to true speech, but **not absent**.

## 6. German error patterns worth reproducing in synthetic data

Confirmed first-hand in the two local runs:

1. **Compound splitting** — `Holzdieb` → `Holz Dieb`, `rundgeschliffen` → `rund geschliffen`,
   `zweitausend` → `zwei tausend`. (Yet long compounds can also come out right: `Gemeinschaftskonto`,
   `Geldautomaten`, `Bezahlungscode`.)
2. **Anglicism spacing / spelling** — `Fairplay` → `Fair Play`, `Marias` → `Maria's` (English
   genitive apostrophe on a German name).
3. **English leakage / code-switching on unclear audio** — `die Karte` → `die Cards`,
   `mehr als ihr` → `mehr than ihr`, and a whole clip decoded as `"You can all kind of schedule
   abden."` This is a real failure mode of a language-auto-detecting model.
4. **Plausible-word substitutions** (not typos) — `Lastschrift` → `Löffel`, `Geld` → `Gate`,
   `nachfragen` → `nachhragen`, `Christian` → `Christoph`. The output stays grammatical-looking, so a
   downstream LLM cannot tell it is wrong.
5. **Fragment/truncation** — an utterance cut off mid-sentence still gets a final period
   (`Ich wollte eine ziemlich hohe Zahlung tätigen und ich bekomme aber keine.`).
6. **Empty output** on noise or unintelligible audio (1/27 clips returned an empty string).
7. **Colloquial contractions preserved** — `Gibt's da ein Limit?`.
8. **Abbreviations written short** — `ca.`, `Dr.`, `bzw.` may or may not be expanded
   (`beziehungsweise` was written out in one clip).
9. **Proper nouns and dialect degrade badly** — one vendor benchmark reports ~55.8 % WER on German
   dialect audio.
10. No evidence either way on `das/dass`, `seit/seid`, `wider/wieder` homophones. Treat homophone
    confusion as plausible but **unproven** — do not over-weight it.

## 7. Method / provenance of the first-hand numbers

- Local model: `~/.local/share/yappr/models/parakeet-tdt-0.6b-v3-int8` (encoder/decoder/joiner int8,
  `tokens.txt` 8,193 pieces).
- Runner: new example `crates/yappr-core/examples/transcribe_file.rs`
  (`cargo run --release -p yappr-core --example transcribe_file -- *.wav`). Delete it if unwanted.
- Audio A (this report): 27 clips from `PolyAI/minds14`, config `de-DE` — **spontaneous** German
  telephone speech, 8 kHz μ-law upsampled to 16 kHz with ffmpeg. Chosen because it contains
  disfluencies and spoken numbers.
- Audio B (companion report): 30 clips from `flozi00/asr-german-mixed` — **read** German at 16 kHz.
- No microphone was used, per the project constraint.
- Caveat: audio A is telephone-band and upsampled, so its word accuracy is worse than the model's
  real quality. Its value is the **formatting** evidence (casing, punctuation, fillers, numbers),
  which is not affected by band-limiting.
